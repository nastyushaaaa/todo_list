# To-Do List

## Описание проекта

To-Do List — консольное приложение на Python для управления списком задач.
Приложение позволяет добавлять задачи, удалять их и отмечать как выполненные.

## Возможности

- Добавление новых задач.
- Удаление существующих задач.
- Отметка задач как выполненных.
- Просмотр списка задач.
- Запрет добавления задач с пустым названием.

## Требования

- Python версии 3.12 или выше.

## Установка и запуск

1. Склонируйте репозиторий:

   git clone https://github.com/nastyushaaaa/todo_list.git

2. Перейдите в директорию проекта:

   cd todo-list

3. Запустите приложение:

   python main.py

## Использование

После запуска появится меню:

1. Добавить задачу.
2. Удалить задачу.
3. Выполнить задачу.
4. Показать задачи.
5. Выход.

Выберите нужное действие, введя соответствующий номер.

## Тестирование

Для запуска автоматических тестов выполните:

   python -m unittest -v

В проекте реализованы четыре теста:

- Проверка добавления задачи.
- Проверка удаления задачи.
- Проверка завершения задачи.
- Проверка запрета добавления пустой задачи.

## Непрерывная интеграция

Для автоматического тестирования используется GitHub Actions.

CI запускается при отправке изменений в ветки:

- main;
- development;
- release.

Также тестирование запускается при создании Pull Request в main.
